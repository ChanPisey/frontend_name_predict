មុខងារ

🔍

ទស្សន៍ទាយឈ្មោះតែមួយ

វាយឈ្មោះខ្មែរ ហើយទទួលបានលទ្ធផលភ្លាមៗ ថាជាភេទប្រុស ឬស្រី រួមជាមួយភាពទុកចិត្ត។

📋

ទស្សន៍ទាយជាក្រុម

ផ្ញើបញ្ជីឈ្មោះអតិបរមា ១០០ ក្នុងមួយលើក ដើម្បីទទួលបានការទស្សន៍ទាយភ្លាមៗទាំងអស់។

⚡

លឿន និងត្រឹមត្រូវ

ប្រើប្រាស់ AI ដ៏ទំនើបដែលបានបណ្តុះបណ្តាល ជាពិសេសសម្រាប់ឈ្មោះខ្មែរ ផ្តល់លទ្ធផលភ្លាមៗ។

🔗

API សម្រាប់អ្នកអភិវឌ្ឍន៍

ភ្ជាប់ API ទៅកាន់កម្មវិធីរបស់អ្នកតាម JavaScript, Python ឬភាសាណាក៏បាន។
