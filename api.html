ទាញយក API

អ្នកអភិវឌ្ឍន៍អាចភ្ជាប់ API នេះទៅកាន់កម្មវិធីរបស់អ្នកបានដោយផ្ញើ សំណើ HTTP មកកាន់ endpoint ខាងក្រោម។

ទស្សន៍ទាយឈ្មោះតែមួយ

POST /predict
        Content-Type: application/json
        {
          "name": "ចន្ទា"
        }

លទ្ធផលដែលទទួលបាន៖


      {
        "name": "ចន្ទា",
        "gender": "Female",
        "confidence": 99.91,
        "probability": 0.9991,
        "kccs": ["ច", "ន្ទា"]
      }

ទស្សន៍ទាយជាក្រុម (អតិបរមា ១០០ ឈ្មោះ)

POST /batch_predict
      Content-Type: application/json

      {
        "names": ["ចន្ទា", "សុខ", "រដ្ឋា"]
      }

ពិនិត្យស្ថានភាព API

GET /health

ឧទាហរណ៍ជាមួយ JavaScript

const res = await fetch('https://yourdomain.com/predict', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ name: 'ចន្ទា' })
      });
      const data = await res.json();
      console.log(data.gender, data.confidence);

ឧទាហរណ៍ជាមួយ Python

import requests

      res = requests.post('https://yourdomain.com/predict',
                          json={'name': 'ចន្ទា'})
      print(res.json())
